# Skill Search Reports

Immutable-ish отчёты команды `FIND SKILL`. Они сохраняют query, inspected candidates и TOP-5, чтобы команда `INSTALL SKILL: #N` могла resolve выбор без истории чата.

Новый поиск создаёт новый `SKILL-SEARCH-<timestamp>.md`; старые отчёты не переписываются ради изменения рейтинга.
