# project-status

Используй для `STATUS PROJECT`. Проверь task statuses, PLAN/STATUS projections, REQ statuses/coverage в `docs/requirements/STATUS.md`, latest reviews и blockers. Lifecycle-status REQ не должен дублироваться в `SPEC.md`. Однозначный projection drift можно исправить. Не меняй смысл REQ/ADR и не пиши product code. Покажи in-progress, blocked, recent completed и unblocked high-priority work.
