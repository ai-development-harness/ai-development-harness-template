# reconcile-project

Используй для `RECONCILE PROJECT`. Сравни code/config/migrations/tests с REQ, Accepted ADR, architecture docs, tasks, evidence и projections. Найди undocumented behavior, stale docs/status, architecture drift и requirement gaps. Production code не исправляй. Однозначные projections можно синхронизировать; substantive gaps → corrective STEP. Сохрани audit report.
