# Requirements Status

> Единственная persisted projection lifecycle-состояния REQ. Определение, rationale, acceptance и traceability каждого требования находятся в его `REQ-NNN-*.md`; `SPEC.md` содержит только индекс. Текущий статус выводится из STEP, verification/evidence и review и не дублируется в canonical REQ или `SPEC.md`.

Допустимые значения:

- `Запланировано` — требование покрыто roadmap, но доказанной реализации ещё нет;
- `Частично` — доказана только часть acceptance/coverage;
- `Выполнено` — необходимый контракт доказан завершёнными STEP, verification/evidence и обязательными review gates;
- `Отложено` — реализация сознательно перенесена;
- `Отменено` — требование сознательно больше не действует.
